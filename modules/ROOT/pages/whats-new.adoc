[[whats-new]]
= What's New in Spring LDAP 4.0

[[whats-new-breaking-changes]]
== Breaking Changes

* https://github.com/spring-projects/spring-ldap/issues/1814[gh-1814] - `CompareFilter` (and therefore `EqualsFilter`, `LikeFilter` and the other comparison filters), `PresentFilter` and `NotPresentFilter` now reject, with an `IllegalArgumentException`, any attribute name that is not a valid https://datatracker.ietf.org/doc/html/rfc4512#section-2.5[RFC 4512 attribute description].
Values continue to be escaped; attribute names are validated and should not come from untrusted input.
See xref:spring-ldap-basic-usage.adoc#basic-queries[Building LDAP Queries].
* https://github.com/spring-projects/spring-ldap/issues/1109[gh-1109] - `ContextSourceAndDataSourceTransactionManager` and `ContextSourceAndHibernateTransactionManager` have been removed since they rely on APIs that are removed in Spring Framework 7; remove any use of the `data-source-ref` and `session-factory-ref` attributes of the XML namespace's transaction manager element.

== Core

* https://github.com/spring-projects/spring-ldap/issues/1110[gh-1110] - Updated to Spring Framework 7
* https://github.com/spring-projects/spring-ldap/issues/1153[gh-1153] - Moved from Spring Framework's nullability annotations to https://jspecify.dev/[JSpecify]
