[[whats-new]]
= What's New in Spring LDAP 4.1

[[whats-new-breaking-changes]]
== Breaking Changes

* https://github.com/spring-projects/spring-ldap/issues/1285[gh-1285] - `spring-data-commons` is no longer an optional dependency of `spring-ldap-core`; applications that relied on `spring-ldap-core` to transmit it transitively must now declare it explicitly.
* https://github.com/spring-projects/spring-ldap/issues/1813[gh-1813] - `CompareFilter` (and therefore `EqualsFilter`, `LikeFilter` and the other comparison filters), `PresentFilter` and `NotPresentFilter` now reject, with an `IllegalArgumentException`, any attribute name that is not a valid https://datatracker.ietf.org/doc/html/rfc4512#section-2.5[RFC 4512 attribute description].
Values continue to be escaped; attribute names are validated and should not come from untrusted input.
See xref:spring-ldap-basic-usage.adoc#basic-queries[Building LDAP Queries].

== Core

* https://github.com/spring-projects/spring-ldap/issues/1404[gh-1404] - Added `map()`, `single()`, `optional()`, `list()`, and `stream()` methods to `LdapClient` search support
